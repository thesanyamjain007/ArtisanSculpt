# ArtisanSculpt

A static website for a handmade products marketplace that empowers artisans and showcases handcrafted goods to a global audience.

Live at [artisansculptlpu.com](https://artisansculptlpu.com)

## Overview

ArtisanSculpt is a single-page marketplace website that connects skilled artisans from underserved communities with conscious consumers. Every product is handcrafted using traditional techniques, and each purchase supports the livelihood of artisans while preserving cultural heritage.

## Features

- **Product Showcase** — Curated handmade products (jewellery, pottery, wall art, home decor, and more) with prices and direct "Buy Now" links to partner marketplaces (Flipkart, ExclusiveLane).
- **Our Vision** — Details the mission around humanitarian services and supporting rural artisans.
- **About Us** — The story behind the platform and its commitment to fair trade.
- **Crafting Process** — Insight into artisanal creation with an embedded video.
- **Gallery** — A responsive photo grid of handmade crafts.
- **Collaborations** — Partner profiles such as Lovely Professional University (LPU).
- **Sustainability** — Eco-friendly materials, ethical production, carbon-neutral shipping, and more.
- **Testimonials** — Customer reviews with ratings.
- **Contact** — A contact form and developer contact info.

## Getting Started

The site is entirely static (HTML + CSS) with no build step or dependencies.

1. Clone the repository:

   ```sh
   git clone <repo-url>
   cd ArtisanSculpt
   ```

2. Open the page in your browser:

   ```sh
   open "website for handcraft industry.html"
   ```

Or serve it locally:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deployment

The site is deployed on GitHub Pages using the custom domain `artisansculptlpu.com` (configured via the `CNAME` file).
